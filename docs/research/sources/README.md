# Literature-search sources

The raw material behind `../LITERATURE_DATABASE.md` and `../RELATED_WORK.md`: two Elicit
exports of candidate papers, and notes from the searches that established which design
directions had already been tried.

Kept because `LITERATURE_DATABASE.md` is a distilled summary — it records what was concluded,
not what was searched. If a claim in the paper is ever questioned, these show where the
positioning came from.

- `elicit-*.csv` — candidate papers with titles, years and abstracts, exported from Elicit.
- `search-summary-*.md` — what a given search returned and how it relates to this project.
- `design-note-*.md` — the design directions those searches suggested, including the
  weather-conditioned routing option that was considered and not taken.
