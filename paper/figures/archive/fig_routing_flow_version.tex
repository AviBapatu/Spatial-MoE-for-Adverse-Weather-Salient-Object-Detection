\caption{\textbf{Routing for one token at one pyramid scale.}
A depthwise $3{\times}3$ convolution supplies local context, which is concatenated with
the token and passed through a two-layer MLP to give eight routing logits.
Input-dependent Gaussian noise is added during training; top-$K{=}2$ then selects two
experts, and the gate weights are a softmax over those two logits only.
Each selected expert is a residual MLP with a $4{\times}$ channel expansion.
Routing entropy is taken over the \emph{full} eight-way distribution, not the selected
pair, and the normalised value is projected and added to the decoder feature so the
decoder can condition on how decisive the router was.}
\label{fig:router}
